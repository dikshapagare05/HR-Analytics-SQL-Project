HR Analytics SQL Project

Project Overview

This project focuses on analyzing employee data using MySQL to generate meaningful HR insights and support data-driven decision-making.

Tools Used

- MySQL
- MySQL Workbench
- SQL

Database Structure

The project contains four tables:

1. Employees
2. Department
3. Attendance
4. Performance

SQL Analysis

A total of 25 SQL queries were performed, covering:

- Total and active employees
- Employee attrition rate
- Average salary
- Salary analysis by department and designation
- Employee performance ratings
- Top-performing employees
- Bonus distribution
- Department-wise headcount
- Gender diversity analysis
- Age distribution
- Average employee tenure
- Monthly new hires
- Attendance rate
- Leave utilization
- Absenteeism rate
- Highest-paying department
- Highest-paying job role
- Promotion eligibility
- Performance rating distribution
- Employee growth trends
- City-wise employee distribution
- Department-wise attrition
- Workforce dashboard metrics

Project Folder Structure

- Dataset – CSV files containing the four database tables.
- SQL Script – SQL queries used for analysis.
- Database Backup – Database backup files.
- Analysis Result – Query outputs and analysis results.
- Screenshots – Screenshots of SQL queries and results.
- Documentation – Project report and documentation.

Key Learning Outcomes

- Understanding relational databases.
- Writing SQL queries for data analysis.
- Using aggregate functions and GROUP BY.
- Analyzing employee, salary, attendance and performance data.
- Generating insights from structured datasets.

Conclusion

This project helped me develop practical SQL skills and understand how database analysis can be used to solve real-world HR analytics problems.
